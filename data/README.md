# Date operaționale

Nu se comit în GitHub fișierele operaționale WMS/WME.

Sursele oficiale rămân în Google Drive. Pentru execuție locală, fișierele pot fi copiate temporar în directoare ignorate de Git, de exemplu:

- `data/raw/`
- `data/input/`
- `data/output/`

Aceste directoare sunt excluse prin `.gitignore`.
